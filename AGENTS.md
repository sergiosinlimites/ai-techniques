# opencode Agent Rules

This file configures opencode behavior for this TIA course project.

## Project Context

This is an educational project for Techniques of Artificial Intelligence (TIA) course containing:

- **PDFs**: Course materials in `*.pdf` files
- **Jupyter Notebooks**: `*.ipynb` files for practical exercises
- **Modules**: NLP, Machine Learning, Neural Networks, Image Processing, Expert Systems

## Cursor Rules Integration

Import and follow the rules from `.cursor/rules/` directory:

- **project-conventions.mdc**: File organization and working with Jupyter/PDFs
- **general-rules.mdc**: Base rules for AI behavior

When working on code tasks:

1. Read relevant .cursor rules first
2. Follow the conventions defined in project-conventions.mdc
3. Use general-rules.mdc for AI behavior guidelines

## Working with Course Materials

- PDFs: Read and extract information as needed
- Jupyter Notebooks: View code, execute if needed, add new notebooks
- Data files: Use supporting datasets appropriately

## File Types

- `*.ipynb` - Jupyter Notebooks (Python 3.11 via mise)
- `*.pdf` - Course PDFs  
- `*.md` - Documentation
- `*.py` - Python scripts if needed
